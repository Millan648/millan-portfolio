# Millan Noor — Developer Portfolio

A responsive personal portfolio built with React and Vite. It includes an introduction, about/skills, selected projects, and a contact section.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

This project is configured for Vercel's standard Vite build settings. Import the GitHub repository into Vercel, set the production branch to `main`, and enable automatic deployments on push.

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
